# Reza Mohammadvand — Personal Website

A bilingual personal website presenting my academic background, professional experience, technical skills, and research interests in computer networks, artificial intelligence, cloud computing, and edge computing.

## Features

- English landing page at `index.html`
- Persian version at `Fa.html`
- Language switcher between the English and Persian pages
- Responsive, slide-based navigation
- Academic and professional timeline
- Skills and contact sections
- Downloadable résumé

The Portfolio section is currently disabled. Its local demo projects in `Sample_works/` are intentionally excluded from this repository.

## Run Locally

No build step is required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/reza-mohammadvand/Personal-Website.git
cd Personal-Website
```

For a more reliable local preview, serve the directory with any static web server. For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
